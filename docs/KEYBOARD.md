# Keyboard Shortcuts

CADUCEUS supports 23 Mailspring-style keyboard shortcuts via Mousetrap.

## Navigation

| Shortcut | Action |
|----------|--------|
| `j` / `↓` | Next email |
| `k` / `↑` | Previous email |
| `d` | Scroll down |
| `u` | Scroll up |
| `enter` | Open selected email |

## Go To

| Shortcut | Action |
|----------|--------|
| `g i` | Go to Inbox |
| `g d` | Go to Drafts |
| `g s` | Go to Sent |
| `g a` | Go to Archive |
| `g x` | Go to Spam |
| `g t` | Go to Trash |
| `g ,` | Go to Settings |

## Email Actions

| Shortcut | Action |
|----------|--------|
| `s` | Toggle star |
| `e` | Archive |
| `#` | Trash |
| `r` | Reply |
| `shift+r` | Reply All |
| `f` | Forward |
| `shift+i` | Mark as read |
| `shift+u` | Mark as unread |
| `* a` | Select all |

## Composer

| Shortcut | Action |
|----------|--------|
| `mod+enter` | Send |
| `esc` | Discard |

## General

| Shortcut | Action |
|----------|--------|
| `c` | Compose new message |
| `/` | Focus search |
| `shift+r` | Refresh inbox |
| `?` | Show shortcut help |

## Notes

- Shortcuts are ignored when focus is inside text inputs, textareas, or contenteditable elements (except `mod+enter` which always works for sending)
- `mod` = `Cmd` on macOS, `Ctrl` on Windows/Linux
